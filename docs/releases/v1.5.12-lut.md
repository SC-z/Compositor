# Compositor 1.5.12 · 中文 / English · macOS 15+

本版合并原项目截至 `63f1013` 的 145 个提交，保留简体中文、语言切换、macOS 15 兼容和 PhotoCraft 风格的 LUT 预设功能。应用版本为 **1.5.12（58）**。

## 下载与安装

- 系统要求：**Apple Silicon（M 系列芯片），macOS 15 或更新版本**。本安装包不支持 Intel Mac。
- 在本 Release 的 Assets 下载 `Compositor-1.5.12-LUT-macOS15-arm64.dmg`，约 **8.3 MB**。`Source code` 是源码，不是安装包。
- 保存工程并退出旧版，打开 DMG，将 Compositor 拖到 Applications，替换旧应用。
- 本包采用本地签名，**未经过 Apple 公证**。首次打开若被拦截，请确认下载来源，再到“系统设置 → 隐私与安全性”选择“仍要打开”。
- 界面支持简体中文、English 和跟随系统。切换语言后需退出并重新打开。

## 本次更新

- 接入 GIF 动画导入、时间轴、逐帧编辑、帧顺序与时间设置，以及 GIF 导出。
- 接入 PDF 页面导入、PSD 画板支持、图层搜索、对齐与分布、图层导出和通道打包。
- 接入新滤镜与光照效果，包括镜头效果、轮廓光、体积光及更多可编辑滤镜图层。
- 接入画笔压感、字体搜索、响应式工具栏，以及上游的选区、高位深和渲染修复。
- 补齐新增界面的中文文案，并修复新代码在 macOS 15 上的编译兼容问题。
- 修复色调对比度的 GPU 输入偏移，避免 Core Image 扩展输入区域后出现像素错位。

## LUT 预设

- 保留 `.cube`、`.3dl`、`.look` 导入、8 个内置预设、实时预览、三线性／四面体插值、抖动和 `.cube` 导出。
- “图层 → 新建调整图层 → 预设”创建可编辑预设图层；“图像 → 预设”直接处理当前图层或蒙版。
- 对 GIF 使用像素预设时，只修改当前帧；其他帧保持不变。支持取消、撤销、重做及工程保存。
- “文件 → 导出 LUT”可导出全部或所选的组外可见调色图层，默认网格点数为 33。
- 模糊、颗粒、噪点、暗角、辉光、RGB 分离、镜头效果、色调对比度和锐化不能表示为 LUT；导出范围包含这些图层时会提示错误。
- LUT 导出保留不透明度和混合模式，不包含蒙版、剪贴关系或组内调整。不自动判断 LUT 的 Log 编码或输入／输出色彩空间，不附带第三方 LUT。

## 工程兼容性

**新保存的工程使用格式 28，旧版应用无法打开。升级前请保留旧工程副本。**

本版可读取格式 1–20 和上游 GIF 格式 27，同时兼容本分支此前的 LUT 工程。旧工程已有的 LUT 输入范围和色彩设置继续按原效果读取。

体积光首次使用会下载深度模型并检查校验和；模型不包含在安装包中。RAW 高光恢复仍需要 macOS 26 和支持的相机。
